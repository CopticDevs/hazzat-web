All exported dependency scope labels are runtime and reachability verdicts are disabled. ## Remaining findings and migration boundaries

- **SVGO / nth-check (#174, #212, #213, #1):** CRA 5.0.1 → @svgr/webpack 5.5.0 → @svgr/plugin-svgo 5.5.0 requires SVGO ^1.2.2. Its css-select 2.1.0 requires nth-check ^1.0.2. Patched versions require a newer SVGR/SVGO API and configuration. The separately compatible postcss-svgo SVGO 2 path is fixed, including #99. No unsupported major override is applied.
- **PostCSS (#25, #138, #189, #191, #199):** the root v8 copy is patched; CRA → resolve-url-loader 4.0.0 still requires PostCSS ^7.0.35. Moving that loader to a PostCSS 8 parent requires a major loader update beyond CRA's ^4 range. Review Sass/source-map and URL-resolution behavior during a toolchain migration.
- **serialize-javascript (#100, #136, #242):** css-minimizer-webpack-plugin 3 and terser-webpack-plugin 5.3.10 require v6; Workbox's rollup-plugin-terser 7 requires v4. Fixes need v7 (at least 7.1.3 for the full exported set), outside those ranges. Coordinated minimizer/Workbox changes must preserve worker serialization and bundle output.
- **webpack-dev-server (#66, #67, #133, #155, #175, #176) and middleware (#225):** CRA requires server ^4.6.0; remaining server fixes require v5.2.6 or later, and middleware requires a newer major than the retained v5.3.4. CRA's startup hooks/configuration need explicit compatibility work. Its development middleware publicPath removes the trailing slash; do not assume the advisory workaround is already applied.
- **uuid (#135):** jest-junit 13.1.0 and sockjs 0.3.24 require ^8.3.2. The advisory concerns v3/v5/v6 methods with caller-provided buffers; inspected callers use v1() in jest-junit and v4() in sockjs without buffers. This reduces demonstrated applicability at these call sites but does not clear the package finding. A compatible parent release/removal is needed before moving beyond the declared range.
- **@tootallnate/once (#134):** Jest 27 → jsdom 16.7.0 → http-proxy-agent 4.0.1 requires major 1. Its observed call waits for socket connect without an AbortSignal option. Keep the version finding open; parent modernization is needed for the patched major.
- **deepmerge (#246):** no patched release is listed. Four retained parents require ^4.2.2: Jest config, @svgr/plugin-svgo, fork-ts-checker-webpack-plugin and @rollup/plugin-node-resolve. These merge tool configuration; no safe compatible removal was identified. Do not downgrade outside parent constraints or dismiss the alert.
