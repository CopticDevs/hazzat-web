# Illuminated booklet covers

The booklet uses the selected second (Eucharistic vine) direction from the public cover studies:
https://hazzat-coptic-cover-gallery.ampleheron11.chatgpt.site/arch-refined.html#eucharistic-vine

`bookletIlluminatedBackground.png` contains the paper, rectangular border and upper vine/cross ornaments only. It was prepared with the built-in image generation editor from the selected study, removing the logo, title, caption, lower vine and standalone arch. The background has no season-specific wording. The framing references informed the original concept; no third-party icon image is included.

PDF text, the official black Hazzat logo, both arch outlines, and the two-tone lower vine are drawn independently. English and Arabic seasonal titles remain selectable text. The front logo is larger and its lower vine smaller than the previous cover. The matching back uses the same illustrated background and frame, a small centered vine, and a discreet Hazzat.com signature.

Both covers use the same arch paths in `BookletCoverFrame.ts`, copied from the approved study. The gold curve is a 16-pixel normal inset of the maroon curve in the 1009-unit artwork coordinate system, with corresponding vertical and base insets. Geometry tests verify the spacing along the curved shoulder. The page size, content layout, footer numbering, padding and print imposition are unchanged.
