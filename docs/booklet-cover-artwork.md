# Illuminated booklet covers

The booklet uses the selected second (Eucharistic vine) direction from the public cover studies:
https://hazzat-coptic-cover-gallery.ampleheron11.chatgpt.site/arch-refined.html#eucharistic-vine

The upper ornaments in `bookletCoverCorners.svg` follow the original illuminated artwork's full acanthus silhouettes, broad scrolls, leaf lobes and connections. The Coptic cross is constructed from four identical rotated curve sequences; its medallion uses two concentric circles with a constant-width band. The old cross and ring are removed from the structural mask before fitting contours, so their irregular traced edges cannot appear underneath the new geometry. The artwork is mirrored from one shared group. There are no embedded bitmaps, SVG blur filters or runtime tracing. No third-party icon image is included.

Leaf veins follow each leaf's primary rib and lobes, with secondary origins snapped onto parent veins. Dark warm-brown contours and scroll centerlines restore the original ink detail; darker branching veins follow the leaf structure. The cross keeps a fine gold keyline with dark ink outlining and center strokes. Fine details are clipped to the connected silhouette. The artwork stays flat: varied vein weights and restrained, low-opacity crease washes give the leaves character. The gold is anchored to `#927344`, matching the lower front-cover grapevine; the ring uses that same solid color. Tiny enclosed pigment gaps are filled while larger scroll counters remain open.

`scripts/build-booklet-corner-vines.py` regenerates the editable SVG and `BookletCoverCorners.json` together from the approved source contours and authored folds. Authoring requires Pillow, numpy and vtracer 0.6.15; these are not application dependencies. Intermediates stay under ignored `.audit/booklet-corner-artwork`. Run the script after changing the ornament.

`BookletCornerRenderer.ts` draws the JSON curves, clipping, axial gold shading and radial grape shading directly into the PDF. Native PDF shading resources are shared between both covers and survive print imposition. The renderer does not rasterize the SVG. Regression tests verify cross symmetry, concentric circle geometry, monotonic matte shading, SVG/JSON synchronization, native PDF shading, mirrored placement, balanced graphics state and image-free cover rendering.

Artwork data loads on the first PDF generation and is reused afterward, keeping it out of the initial website bundle. Parsed curves are cached across mirrored ornaments, covers and subsequent booklets; document-specific color/opacity resources stay separate. Failed data loads can be retried.

Only the intentional limestone paper texture (`bookletLimestonePaper.png`) remains a raster background. The old `bookletIlluminatedBackground.png` is retained as a design reference and is no longer loaded by the generator. Rectangular borders, corner ornaments, PDF text, the official black Hazzat logo, both arch outlines, and the two-tone lower vine are drawn independently. English and Arabic seasonal titles remain selectable text. The matching back uses the same vector ornaments and frame, a small centered vine, and a discreet Hazzat.com signature.

Both covers use the same arch paths in `BookletCoverFrame.ts`, copied from the approved study. The gold curve is a 16-pixel normal inset of the maroon curve in the 1009-unit artwork coordinate system, with corresponding vertical and base insets. Geometry tests verify the spacing along the curved shoulder. The page size, content layout, footer numbering, padding and print imposition are unchanged.
